# Data Codebook Viewer

연구용 공공·행정 데이터셋의 변수 설명과 코드값을 웹에서 쉽게 확인할 수 있도록 정리한 HTML 코드북 저장소입니다.

## 현재 포함된 문서

- `맞춤형 자료 제공 컬럼 레이아웃_2026_v1.xlsx` — 맞춤형연구DB 6개 테이블
  (자격 및 보험료 BFC, 사망자료 DTH, 청구명세서 T20, 진료내역 T30,
  상병내역 T40, 처방상세내역 T60)
- `일반건강검진 자료 제공 컬럼 레이아웃_260527.xlsx` — 일반건강검진 4개
  연도구간(2002-2008, 2009-2017, 2018, 2019-2024), 각 구간은 문진/검진 결과로 구분

## 뷰어 사용법

`index.html`을 브라우저로 열면 `테이블 구분`·`변수명` 두 개의 셀렉트로 카드를
걸러 볼 수 있습니다.

- 일반건강검진은 연도구간별로 컬럼명·코드값이 달라져 구간마다 별도 테이블로 넣었습니다.
  테이블을 `전체`로 두고 변수명만 고르면 같은 변수의 구간별 카드가 나란히 나옵니다.
- 구간 안에서도 코드값이 연도마다 다른 변수는 값 표에 `적용연도` 열이 붙습니다.
- 구간 전체가 아니라 일부 연도에만 있는 변수는 비고에 `제공연도`가 표시됩니다.
- 코드값 없이 형식·단위만 적힌 변수(`YYYY`, `cm단위` 등)는 `세부설명` 표로 나옵니다.
- 명세서목코드(`ITEM_CD`)처럼 원본에서 소제목으로 나뉜 코드값은 소제목 행으로 묶입니다.

## 파일 구조

```text
.
├── assets/
│   ├── 맞춤형 자료 제공 컬럼 레이아웃_2026_v1.xlsx
│   └── 일반건강검진 자료 제공 컬럼 레이아웃_260527.xlsx
├── tools/
│   └── build_nsc_custom_columns.R
├── index.html
└── README.md
```

## 업데이트

`assets/`의 원본 엑셀이 바뀌면 빌드 스크립트를 다시 실행해 `index.html`을 재생성합니다.
스크립트는 자기 위치를 기준으로 저장소 루트를 찾으므로 실행 위치는 상관없습니다.
필요한 R 패키지는 `data.table`, `readxl`, `jsonlite`, `xml2`입니다.

```bash
Rscript tools/build_nsc_custom_columns.R
```
